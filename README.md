# Heart Disease Federated Learning — ONE SITE

This is the unified single React/Vite site containing:
- Login
- Admin Dashboard
- Hospital Dashboard
- User/Patient Dashboard

All four are available from one deployed website. The role switch at the top is a frontend demo navigation control.

## Render
Root Directory: leave EMPTY
Build Command:
npm install && npm run build

Publish Directory:
dist

Do NOT put vite.config.js into package.json. They are separate files.

This is frontend-only/demo navigation. Backend/database/real ML authentication are not connected yet.
