# Heart Disease FL React GUI

Frontend-only React GUI with role-based navigation.

Login roles:
- Admin
- Hospital / Client
- User / Patient

Admin has individual Hospital list and individual hospital detail pages.
Hospital has individual client pages for training, updates, FL activity, model and settings.
User has dashboard, prediction, history, about, profile and settings.

No backend, API, database, real authentication, or real ML connection is included.

Render:
Build Command: npm install && npm run build
Publish Directory: dist
